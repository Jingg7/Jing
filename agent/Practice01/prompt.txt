你是一名 Python 开发工程师。请在我的 Python 项目中创建以下文件：chat.py、config.ini、requirements.txt。

一、config.ini 要求
请创建 config.ini，内容格式如下：
[llm]
base_url = xxx
api_key = xxx
model = xxx

[assistant]
name = xxx

说明：
1. base_url、api_key、model 用于连接 OpenAI 兼容接口。
2. assistant.name 是当用户问“我是谁？”时返回的名字。
3. 如果 api_key 不需要，可以写成 not-needed。
4. 所有值都允许用户后续手动修改。

二、chat.py 功能要求
1. 使用 configparser 读取 config.ini。
2. 从 [llm] 读取 base_url、api_key、model。
3. 从 [assistant] 读取 name，默认值为 xxx。
4. 使用 openai 官方 Python SDK 创建客户端：
   from openai import OpenAI
   client = OpenAI(base_url=base_url, api_key=api_key)
5. 程序启动后进入聊天循环，使用 input() 读取用户输入。
6. 当用户输入去掉首尾空格后等于“我是谁？”或“我是谁?”时：
   - 不调用 LLM。
   - 先输出一行三个减号：---
   - 再输出一行：我是{name}
   - 然后继续等待下一次输入。
7. 其他输入时：
   - 把用户消息加入 messages 历史。
   - 调用 client.chat.completions.create(model=model, messages=messages)。
   - 打印模型返回内容。
   - 把模型回复加入 messages 历史。
8. 输入 exit、quit 或 退出 时结束程序。
9. 如果 config.ini 缺失，或 base_url、model 为空，要给出友好提示。
10. 调用 LLM 出错时捕获异常并打印错误信息，不要直接崩溃。
11. 包含 main 函数和 if __name__ == "__main__": 入口。
12. 代码使用 UTF-8，中文注释，简洁清晰。
